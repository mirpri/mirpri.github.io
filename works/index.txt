This page showcases some of my personal projects and contributions. Each project reflects my interests in AI systems, software development, and practical applications of technology. Below are brief descriptions of each project, along with links to their respective repositories or live versions.

## Mirshare
Mirshare is a lightweight file-sharing platform for uploading and downloading files, built with React + Vite, a Hono API on Cloudflare Pages Functions, and Cloudflare R2/D1 for storage and metadata, with Mirpass handling authentication. [GitHub](https://github.com/mirpri/mirshare)

## Mirpass
Mirpass is a secure, lightweight, and fully self-hostable single sign-on (SSO) and identity platform for developers. It provides centralized login through a simple HTTP/JSON protocol, an analytics dashboard with real-time DAU and traffic charts, and a polished React + Ant Design interface backed by a high-performance Go backend. [Sign up](https://pass.mirpri.com/)

## NeonVocab
NeonVocab is a modern, AI-powered vocabulary learning application built with React and TypeScript. Master new words with an elegant, distraction-free interface featuring dynamic theming, smart progress tracking, daily challenges, and streaks. [Open](https://mirpri.com/neonvocab)

![screenshot](https://github.com/mirpri/neonvocab/raw/master/res/screenshot1.png)

## HUST Schedule ICS
hust_schedule_ical is a cross-platform tool that turns your HUST (华中科技大学) course schedule into a standard iCalendar (`.ics`) file, ready to import into Google Calendar, Apple Calendar, Outlook, or any phone calendar. It handles the Hub login flow, automatically switches between summer and winter schedules, and remembers your settings. [GitHub](https://github.com/mirpri/hust_schedule_ical)

## MirNotes
This document is a collection of my personal notes and observations as I dive into learning the C programming language and more. As I continue to study and experiment with coding, I record newly discovered features, tips, and techniques that I find particularly useful. Whether you're a beginner or looking to refine your coding skills, these notes might offer some valuable insights.

To explore my ongoing learning journey, access the full notes [here](https://mirpri.com/mirnotes).

## Roads
Roads is a strategy game where you manage traffic flow and plan the most efficient routes, drawing inspiration from the famous game *Mini Metro (R)*. Test your planning skills and challenge yourself with increasingly complex city layouts, optimizing your traffic system to keep everything running smoothly.

For more about the game mechanics, updates, and development details, visit the [GitHub repository](https://github.com/mirpri/Roads).

## Pong-N
Pong-N is a modern twist on the classic arcade game Pong. With updated visuals and smoother gameplay, this version takes the traditional concept and elevates it to a new level. Challenge your reflexes and see how far you can go in this timeless game with a fresh perspective.

Experience enhanced gameplay with added logging and model loading features, perfect for AI enthusiasts looking to dive deeper into the mechanics.

![screenshot](https://github.com/Mirpri/Pong-N/assets/71537369/c72c3cf3-fb53-4393-ac9b-0f6390d2efa6)

For a detailed overview of the game, including features and enhancements, visit the project on [GitHub](https://github.com/mirpri/Pong-N).
